## Design Context

> **Authoritative spec: [DESIGN.md](DESIGN.md) (Modern Sideline).** This file is the short design context that design skills read first. If anything here, in a skill, or in generic design advice conflicts with DESIGN.md, DESIGN.md wins. Do not propose a new visual direction, palette or typeface; critique and polish *against* DESIGN.md.
>
> Approved choices that override generic skill rules: **Inter** is the UI typeface, **white `#FFFFFF` surfaces** on a near-white `#F9FAF8` canvas are intended in light mode, and **dark is the default theme** (decision U4, 2026-10-20), with light fully supported. Any generic "avoid Inter", "never pure white" or "pick a bolder direction" rule does not apply to this project.

### Users
Volunteer coaches, parent coaches and team managers running youth and grassroots football matches. They use the app **outdoors**, on the sideline, in daylight, often one-handed and under moderate stress. The device is a phone at arm's length, possibly with glare. They are not professionals: they make substitution decisions in real time without coaching staff.

The job to be done is to keep playing time fair and run the match without thinking about the interface.

### Brand Personality
**Fast. Clear. Fair.** The emotional goal during a live match is **calm control under pressure**. The interface should reduce stress, not add to it.

The visual tone is a well-made physical tool with a football soul: a grass pitch, shirt-number discs and a club-green scoreboard on the match surfaces, and quiet utility everywhere else.

Anti-references: enterprise dashboards; gamified or broadcast sports UI (FIFA-style); betting-app condensed caps headlines; legacy club tools with small crowded UI; glassmorphism, glow, gradients or decorative layers.

### Aesthetic Direction
- **Theme:** **dark is the default** (U4). Light (near-white `#F9FAF8` canvas, white surfaces, subtle neutral hairlines) is fully supported and suits bright daylight. Both keep the same scoreboard, grass and accents; only the surfaces change.
- **Colour roles:** **lime `#9FE870` = "your next action"** (fill, ring or underline only; never text on light). **Club green `#0E4D33` = identity** (scoreboard, fixture panel, shirt discs; never a button fill). Neutrals carry everything else. No indigo, purple, glow or gradients.
- **Typography:** **Inter** for every word. **Barlow Condensed 600**, bundled locally, for match numerals only (score, clock, shirt numbers). No other families.
- **Geometry:** pills for actions, discs for players, hairlines for lists, a 20px radius for things that slide.

### Design Principles
1. **Readability first.** Outdoor light, one hand: live text ≥ 13px, names ≥ 14px, targets ≥ 44px, text contrast ≥ 4.5 : 1 (the palette measures ≥ 6 : 1).
2. **Lime is signal, neutrals are structure.** If it is lime, it is the thing to tap now.
3. **Calm through hierarchy.** Normal states are silent, and only exceptions speak. There is one "what now" slot (the action strip).
4. **Predictable speed.** Fixed placement, no layout shift, every live mutation undoable or correctable.
5. **Honest structure.** No decorative chrome. If an element cannot justify itself functionally, it does not exist.
